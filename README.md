# SIH-FarmerMarketplace
A repository to store and manage relevant data and programs related to SIH26033(TO create a digital marketplace for farmers to be able to sell produce directly to consumers)
#How to run
Step 1: Download and extract the code 
Step 2: Open a terminal with working directory [Frontend](farm-market/farm-market-frontend/) and run the following commands-
npm install
npm run dev
You should obtain a link like (localhost://5173)
Step 3: Open a terminal with working directory [Backend](farm-market/farm-market-backend/) and run the following command-
python manage.py runserver
You should obtain a "Development server running" message and a link like (https://127.0.0.1.8000/)
Paste the link acquired in Step 2 in your browser. You should be redirected to the home page of the marketplace portal
Keep both the terminals running for as long as the app is needed to run.
